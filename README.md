# Корпорация РС — официальный сайт

Статический одностраничный сайт ООО «КОРПОРАЦИЯ РЕСУРС СТРОЙ».

Публикация настроена через GitHub Pages из ветки `main`.

Живая версия: https://texas359-art.github.io/corporation-rs-site/

Текущий дизайн собран как проектно-архитектурная витрина: четыре направления домов, внешний вид и интерьерный референс для каждого направления, отдельный проект «Простор RS 8×8», корпоративные сведения, этапы строительства, FAQ и контакты.

Перед ручным редизайном сохранена ветка `backup-before-handmade-redesign`.
